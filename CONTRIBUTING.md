# Contributing

Thanks for contributing to Speak2Type.

## Development Setup

```bash
make deps
make build
```

## Tests

```bash
make test
```

## Coding Guidelines

- Keep changes focused and small.
- Prefer existing patterns in `internal/` and `pkg/`.
- Avoid introducing new dependencies unless needed.

## Pull Requests

- Describe the problem and solution clearly.
- Include test steps or logs when applicable.
- Note any behavior changes or compatibility risks.
